# OpenFOAM headers

Use `openfoamHeaderESI.in` for source compiled against OpenFOAM.com and `openfoamHeaderFoundation.in` for source compiled against OpenFOAM Foundation. Preserve upstream copyright and licence notices when a file is copied or substantially derived from another project.

Templates in this directory are source assets, not generated build output. Add a subdirectory only when several templates share one stable purpose, such as OpenFOAM headers or scheduler jobs. Keep site-specific accounts, partitions, module paths and filesystem locations outside tracked templates.
