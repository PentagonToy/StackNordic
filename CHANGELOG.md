# Changelog

## 0.1.0 - 2026-09-27

- Reconstruct decomposed OpenFOAM.com and OpenFOAM Foundation cases from Python or the command line.
- Export reconstructed and decomposed fields into Cartesian datasets without requiring permanent reconstruction.
- Compute declared combustion fields, package HDF5 datasets, and compile snapshot series.
- Filter and downsample DNS datasets with Reynolds, Favre, variance, and SGS reductions.
- Run the supported OpenFOAM and stored-data post-processing operations through one API.
